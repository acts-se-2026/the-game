Rooms

1. Loading page
- enter username
- confirm button -> 2.

2. Lobby
- list of public lobbies:
    - Room name
    - Number of players
    - Join button
    -refresh lobbies button
- create room button -> 3.2

3.1. Waiting for a match to start
- Leave Button -> 2.
- Room ID   
- List of players
- if the host starts the game, all players enter the game arena

- Players can see when others join and when the host has decided to start the match

3.2. Making a room
- Room ID
- List of players
- Start match button -> 4.
- Leave Button -> 2.

- The host can see all the players that are in the waiting room, can kick them out of the room and can start the match for all the players

4. Game arena
- Obstacles (destructable and non destructable)
- Players
- In game controls
- in game UI (settings, ...)
